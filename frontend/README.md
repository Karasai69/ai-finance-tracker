# Сборка 3D-монеты

`coin3d.js` — исходник монеты на Three.js. Сайт использует собранный и сжатый файл
`app/static/coin3d.js`: в нём только нужные части Three.js, он загружается уже после
открытия страницы и не мешает остальному интерфейсу.

Пересобрать после изменений:

```bash
cd frontend
npm install
npm run build
```
